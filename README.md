## 🎯 About Me

I'm a **graduate research assistant and master's student at North Dakota State University (NDSU)**, working on **out-of-distribution (OOD) detection** — the problem of models that answer confidently when they see something they were never trained on.

Before NDSU I worked as a **full-stack software developer at a startup in Ghana** (4+ years, web and mobile). That's still how I think: if it doesn't run, it doesn't count.

- 🌍 **Based in:** Fargo, ND, USA
- 🎓 **Research:** OOD detection methods and benchmarks (OpenOOD), and a survey of OOD evidence
- ✍️ **Writing:** plain-English breakdowns of ML on [dev.to](https://dev.to/oasolomon)
- 🛠️ **Previously:** full-stack software developer, Ghana
